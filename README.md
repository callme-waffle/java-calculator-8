# java-calculator-precourse

## A. 문제 분석

### 1) 주요기능
> 문자열 입력에 대해 구분자를 기준으로 분리된 내부 양수값을 더한 값을 출력하는 프로그램

### 2) 주요조건
- ',' 또는 ':'를 사용하여 숫자를 구분함
- '//'과 '\n' 사이에 입력되는 문자를 '커스텀 구분자'로 사용할 수 있음

### 3) 구현 예외조건
- 주어진 양의 정수에 대한 총합은 java21에서 지원하는 int 범위 내에 있음을 전제로 한다.
- 커스텀 구분자 구현 시 '/' 및 '\', '\n'은 구분자로 사용할 수 없다.

## B. 구현기능 

- [ ] 기본 입/출력 기능
- [ ] 입력 문자열 내 숫자 추출기능
- [ ] 커스텀 구분자영역 분리기능
- [ ] 커스텀 구분자 추출기능
